# ArthaFlow Book: downloads

Official installers for **ArthaFlow Book**, the accounting app for fish traders.

- **Android**: `ArthaFlow-<version>.apk`
- **Windows 10/11 (64-bit)**: `ArthaFlow-Setup-<version>.exe`

Open [Releases](../../releases/latest) for the newest version. The app also
updates itself from here: it shows a message when a new version is ready.

This repository holds only the installers. It has no source code.

## Installing

**Android:** open the downloaded APK. If Android asks, allow "Install unknown
apps" for your browser or file manager, then tap Install.

**Windows:** run the setup file. If Windows shows "Windows protected your PC",
click **More info**, then **Run anyway**.
